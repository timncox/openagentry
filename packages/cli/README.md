# @openagentry/cli

The `agentry` CLI binary — operator surface for [OpenAgentry](https://openagentry.dev).

## Install

```bash
npm install -g @openagentry/cli
# or
pnpm add -g @openagentry/cli
```

## Use

```bash
agentry version
agentry help
agentry doctor
agentry list
agentry capabilities
```

Every command supports `--json` for machine-readable output and `--help` for usage.
